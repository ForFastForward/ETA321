## 7 分鐘，不只是 7 分鐘

> 成日搭屯馬綫、東涌綫嘅你，見到下一班要等 7 分鐘，嗰刻先開始後悔：「如果頭先行快兩步就好啦……」如果趕得切上一班車，就唔使企喺個又熱又焗嘅月台，眼白白望住個「7分」慢慢變成「6分」。

ETA321 嘗試將港鐵同巴士常見嘅到站分鐘，變成更實在嘅分秒倒數，再配合列車位置推算同 Live Activity，令你更清楚掌握每一秒。

## 功能

| | 功能 | 說明 |
| :--: | --- | --- |
| 🔵 | 分秒 ETA 倒數 | 將公開 ETA 轉化為穩定、易讀的預估倒數。 |
| 🚇 | 港鐵路線與列車位置 | 支援港鐵 ETA、路線地圖及列車位置推算。 |
| 🚌 | 城巴及九巴 ETA | 在同一個介面查看已選路線的巴士到站預估。 |
| 📱 | Live Activity | 將已選路線的 ETA 顯示在 iPhone 鎖定畫面及動態島。 |

## 資料來源與使用權限

ETA321 使用經 DATA.GOV.HK 發布的公開交通資料，並按其使用條款取得、整理、結合及以本機運算方式呈現 ETA。

- [港鐵即時列車資料](https://data.gov.hk/en-data/dataset/mtr-data2-nexttrain-data) — 知識產權權利人：MTR Corporation Limited
- [九巴即時到站資料](https://data.gov.hk/en-data/dataset/hk-td-tis_21-etakmb) — 經運輸署發布；原始資料權利人包括 The Kowloon Motor Bus Company (1933) Limited 及 Long Win Bus Company Limited
- [城巴即時到站資料](https://data.gov.hk/en-data/dataset/ctb-eta-transport-realtime-eta) — 知識產權權利人：Citybus Limited
- [DATA.GOV.HK 使用條款及條件](https://data.gov.hk/tc/terms-and-conditions)

ETA321 為獨立開發的資訊工具，並非港鐵、九巴、城巴、DATA.GOV.HK 或任何營辦商的官方服務，亦不代表獲其認可。到站時間及分秒倒數均屬預估資訊，請以營辦商官方公告及現場資訊為準。
